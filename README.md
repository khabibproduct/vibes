# LILU Drinks

Сайт безалкогольного бара LILU Drinks: бабл ти, крафтовые лимонады, безалкогольные коктейли и чай.

Статический сайт без сборки: откройте `index.html` в браузере или выложите папку на любой хостинг (GitHub Pages, Netlify, Vercel).

## Файлы

- `index.html` — разметка страницы
- `styles.css` — стили и брендовые токены (цвета, шрифты)
- `main.js` — меню, конструктор бабл ти и SVG-стаканы

## Бренд

- Цвета: `#0250B0` (синий), `#D2FF42` (лайм), `#C6D1DE` (туманный серо-голубой)
- Шрифты: Climate Crisis (логотип и английские названия), Onest (русский текст), Martian Mono (подписи, объёмы)

## Что заменить перед запуском

- Цены, составы и объёмы — массив `CATEGORIES` в `main.js`; валюта — константа `CURRENCY`
- Цены конструктора — объект `BUILDER` в `main.js`
- Адрес, часы работы и соцсети — секция `#visit` в `index.html` (сейчас там заглушки)
