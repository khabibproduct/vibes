# Карточки — аналог Quizlet

Веб‑приложение для заучивания чего угодно с помощью карточек. Работает целиком в браузере:
без сервера, без сборки и без зависимостей. Данные хранятся в `localStorage`.

## Возможности

- **Наборы карточек** — создание, редактирование, удаление, поиск по наборам и терминам.
- **Импорт** из Word / Excel / Google Таблиц: вставьте текст, выберите разделители
  (Tab, запятая, тире, точка с запятой; новая строка или пустая строка между карточками).
- **Экспорт** набора в буфер обмена (термин и определение через Tab).
- **Режимы обучения:**
  - 🗂️ **Карточки** — переворот, «Знаю / Ещё изучаю», отмена, перемешивание,
    повтор только незнакомых карточек.
  - 🧠 **Заучивание** — адаптивные раунды по 7 карточек: сначала выбор из вариантов,
    затем письменный ответ. Ошибки возвращаются в конец раунда, прогресс сохраняется.
  - 📝 **Тест** — вопросы «верно/неверно», выбор ответа и письменные; итоговый балл и разбор.
  - ⚡ **Подбор** — соберите пары на время (штраф +1 с за ошибку), рекорд сохраняется.
- Письменные ответы проверяются мягко: регистр, `ё/е`, пунктуация не важны; допускаются опечатки;
  если в определении несколько вариантов через `,` `;` `/` — подойдёт любой.
- Отвечать **термином или определением**, учить **только отмеченные ★** карточки.
- Озвучка терминов (Web Speech API), горячие клавиши, тёмная тема, мобильная вёрстка.

### Горячие клавиши

| Режим | Клавиши |
| --- | --- |
| Карточки | `Пробел` — перевернуть, `←` — ещё изучаю, `→` — знаю, `Backspace` — отменить |
| Заучивание | `1`–`4` — выбрать вариант, `Enter` — продолжить |
| Редактор | `Tab` в последнем поле — новая карточка, `Ctrl/⌘ + Enter` — сохранить |

## Запуск

ES‑модули не загружаются по `file://`, поэтому нужен любой статический сервер:

```bash
npm start            # python3 -m http.server 8000
# открыть http://localhost:8000
```

Подойдёт и GitHub Pages — достаточно опубликовать корень репозитория.
